# Contributing

WaterPrint is being developed as an open measurement and resource-awareness project.

Before contributing:
1. Run `npm install`.
2. Run `npm run check`.
3. Run `npm run security`.
4. Do not commit secrets, prompt content, credentials, or private user data.
5. Keep estimation methodology changes versioned and documented.

Environmental claims require particular care. Do not convert estimates into measured or verified claims without an explicit methodology and verification layer.
